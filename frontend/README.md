# ORCA frontend

Next.js/TypeScript client for ORCA. See the [repo root README](../README.md) for the
full project overview, setup instructions, and architecture.

```bash
npm install
npm run dev      # expects the backend at http://localhost:8000, override via NEXT_PUBLIC_BACKEND_URL
npm test         # Vitest unit tests
npx tsc --noEmit # type-check
```
